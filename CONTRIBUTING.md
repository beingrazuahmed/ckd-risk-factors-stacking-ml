# Contributing

Research code improvements are welcome as issues or pull requests. Please describe the affected notebook, evidence of the bug, Python/library versions, and reproducible steps. Do not upload private medical records, identifiers, restricted hospital datasets, unlicensed figures or proprietary code.

Scientific changes to dataset processing, split definitions, feature selection, SMOTE handling, model hyperparameters, and scoring should be marked clearly as **new analyses**, rather than being silently substituted for the archived paper workflow. Include any new evaluation or regression tests, and update `METHODS_AND_LIMITATIONS.md` if appropriate.

By submitting a contribution you agree that you have the rights to submit it under the repository code license. For security-related issues, see `SECURITY.md`.
